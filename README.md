## این پروژه چیست؟

سیگنال هوش داده‌های پراکنده‌ی بازار و جامعه‌ی ایران را از منابع مختلف جمع‌آوری،
پاک‌سازی و در یک داشبورد واحد قابل‌فهم می‌کند. به‌جای سر زدن به ده‌ها سایت جدا
برای قیمت دلار، اخبار، یا روند جستجوی گوگل، همه‌چیز در یک صفحه‌ی سریع و
راست‌چین کنار هم است — با بروزرسانی خودکار، بدون نیاز به لاگین.

هر بخش یک صفحه‌ی مستقل و واقعی سمت سرور دارد (نه یک صفحه‌ی تک با جاوااسکریپت)،
یعنی هم برای کاربر سریع بارگذاری می‌شود و هم برای موتورهای جستجو کاملاً
قابل‌خواندن است.

## بخش‌های داشبورد

| بخش | چه چیزی نشان می‌دهد |
|---|---|
| 🏠 **خانه** | خلاصه‌ی زنده از هر ۹ بخش در یک نگاه |
| 🔍 **ترند سرچ** | پرجست‌وجوترین کلیدواژه‌های گوگل در ایران، به‌همراه تاریخچه و تحلیل هوش مصنوعی |
| 📰 **ترند اخبار** | رصد لحظه‌ای ده‌ها کانال خبری تلگرام، با ترجمه‌ی خودکار منابع غیرفارسی و بایگانی کامل قابل جست‌وجو |
| 💰 **ترند مالی** | دلار، طلا، سکه، ارز دیجیتال، بورس تهران، و نزدیک به ۱۰۰ کالای جهانی (نفت، فلزات، محصولات کشاورزی) |

| 🛒 **ترند کالا** | پرفروش‌ترین‌ها و روند قیمت در بازار آنلاین کالای ایران |

| 🎯 **ترند پلی‌مارکت** | بازارهای پیش‌بینی مرتبط با ایران، ترجمه‌شده و رتبه‌بندی‌شده |
| 🔮 **پیش‌بینی ترند** | موتور کشف زنجیره‌ی علّی بین بخش‌ها — با کارنامه‌ی شفاف و صادقانه‌ی دقت پیش‌بینی، نه فقط ادعا |

## معماری، در یک نگاه

```
کرالرها/شنودگرها  →  SQLite (هر ماژول دیتابیس خودش)  →  لایه‌ی رندر سمت سرور  →  کاربر
   (زمان‌بندی‌شده)         (WAL mode)                    (EJS، صفحات مستقل)
```

- **دو پروسه‌ی PM2** روی سرور: یکی جمع‌آوری و پردازش داده (کرالرها، هوش
  مصنوعی، زمان‌بندها) و دیگری رندر سمت سرور صفحات عمومی — کاملاً جدا از هم،
  تا کندی یک کرالر روی سرعت سایت اثر نگذارد.
- هر ماژول دیتابیس SQLite مستقل خودش را دارد؛ بدون وابستگی مشترک شکننده.
- سئو به‌صورت جدی رعایت شده: هر تب و هر رکورد (خبر، منطقه، محصول) آدرس
  مستقل و قابل ایندکس دارد، به‌همراه `sitemap.xml` پویا و داده‌ی ساخت‌یافته
  (JSON-LD).
- پشت Cloudflare و nginx با میکروکش لبه، برای تاب‌آوری در برابر ترافیک بالا.

## پشته‌ی فنی

Node.js · Express · EJS · better-sqlite3 · Puppeteer · PM2 · nginx · Cloudflare

## اجرای محلی

```bash
git clone https://github.com/alirezamoni/Signal_Hoosh.git
cd Signal_Hoosh
npm install
cp .env.example .env   # مقادیر واقعی را در .env پر کنید — هرگز کامیت نشود
npm start
```

تمام مقادیر لازم (کلید OpenRouter، اطلاعات تلگرام، رمزهای JWT و غیره) در
`.env.example` مستند شده‌اند.
